Небольшая консольная утилита для DNS-запросов в Linux. Она отправляет
запросы по UDP и самостоятельно разбирает ответы, без библиотек-резолверов.

Поддерживаются записи A, AAAA, MX, NS, CNAME и TXT. В выводе указаны имя,
TTL, тип и значение записи, а также время ответа сервера.

## Сборка и запуск

```sh
make
./dnsq example.com
./dnsq example.com -t AAAA
./dnsq example.com -t MX -s 8.8.8.8
./dnsq --help
```

По умолчанию запрашивается запись A у первого сервера `nameserver` из
`/etc/resolv.conf`. Параметр `-s` принимает IPv4- или IPv6-адрес. Время
ожидания ответа - три секунды. При ошибке программа завершается с ненулевым кодом.

Пример вывода:

```text
example.com	300	A	93.184.216.34
Response time: 12.47 ms
```

## Проверка

```sh
make test
make sanitizers
```

Если сервер пометил UDP-ответ как обрезанный, программа сообщает об ошибке.
Переключения на TCP и собственного рекурсивного разрешения имён нет.
